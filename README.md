# -jan-qr-label-maker
​A zero-dependency offline single-file HTML tool that generates EAN/JAN barcodes and multi-purpose QR codes, formatted and optimized for A4 printing and label layouts.


# JAN & 多機能QR ラベルメーカー (jan-qr-label-maker)

外部ライブラリやCDNに一切依存せず、ブラウザ単体（完全オフライン）で **JANバーコード（EAN-13 / EAN-8）** と **多機能QRコード（URL・自由テキスト・連絡先など）** を生成し、ラベル名とセットでA4用紙に自動レイアウト・印刷できるシングルHTMLツールです。

---

## 主な特徴

* **完全ゼロ依存・オフライン動作**
  外部CDNやサードパーティ製ライブラリを一切使用せず、純粋なVanilla JavaScriptのみでエンコードからCanvas描画まで完結します。セキュリティ制限のある社内PCやオフライン環境でも確実に動作します。
* **JANコード自動判定＆チェックデジット補完**
  * 13桁（標準）および8桁（短縮）のJANバーコードに対応。
  * 末尾のチェックデジットを省いた12桁・7桁を入力した場合も、自動で計算して補完します。
* **多機能QRコード生成**
  * URL（ウェブサイト・SNS・ショップページ）や自由テキスト、連絡先などをUTF-8のQRコード（Version 1〜6 / 誤り訂正レベルM）へ変換します。
* **一括登録＆キーボード操作最適化**
  * ExcelやGoogleスプレッドシートから「コード・URL」と「ラベル名」の2列をコピー＆ペーストするだけで一括展開できます（種別も自動判定）。
  * 1件ずつの連続入力時は、`Enter` キーのみでスムーズにフォーカス移動・リスト追加が可能です。
* **A4レイアウト＆印刷最適化 (`@media print`)**
  * 横の列数（2列・3列・4列）や切り取り線（点線）の有無をリアルタイムで切り替え可能。
  * 印刷ボタンを押すと操作パネルが自動で非表示になり、A4縦サイズのラベルシートのみが美しく印刷・PDF保存されます。

---

## 使い方

1. `index.html`（またはダウンロードしたHTMLファイル）をChromeやEdgeなどのブラウザで開きます。
2. **1件ずつ追加** または **一括追加** から、JANコード・URL・テキストとラベル名を入力してリストに追加します。
3. 右側のA4プレビューを確認しながら、列数（2列 / 3列 / 4列）や枠線の有無を調整します。
4. 画面左下の **「🖨️ A4サイズで印刷 / PDF保存」** ボタンをクリックして出力します。
   ※ブラウザの印刷設定で「余白：なし」または「デフォルト」を選択すると、A4用紙ぴったりに収まります。

---

## 技術仕様

* **構成:** 単一HTMLファイル（HTML5 / CSS3 / Vanilla JavaScript）
* **バーコード規格:** JAN / EAN-13, EAN-8
* **QRコード規格:** Model 2 / Byteモード（UTF-8対応） / Version 1〜6 / 誤り訂正レベル M（ガロア体 $GF(2^8)$ リード・ソロモン符号を自前実装）
* **動作環境:** Google Chrome, Microsoft Edge, Safari, Firefox などのモダンブラウザ
